# HranGor — установщики

Здесь публикуются установщики HranGor — приложения, которое показывает конфигурацию 1С из Gitea в виде дерева и для каждого объекта, реквизита, формы и модуля показывает, кто, когда и что менял.

## Установка

1. Откройте [последний релиз](https://github.com/butvinskiyvsr-cmyk/hrangor-releases/releases/latest) и скачайте `HranGor-Setup-<версия>.exe`.
2. Запустите его. Права администратора не нужны — приложение ставится в профиль пользователя.
3. Нужен установленный [Git for Windows](https://git-scm.com/download/win) и доступ к Gitea из рабочей сети.

При первом запуске приложение один раз скачивает репозиторий конфигурации (около минуты), дальше получает только новые версии.

## Обновления

Приложение само проверяет этот репозиторий при запуске и каждые 4 часа, скачивает новую версию в фоне и предлагает перезапуститься. Ничего удалять и ставить заново не нужно.

Windows может предупредить, что издатель неизвестен (установщик не подписан сертификатом): «Подробнее» → «Выполнить в любом случае».
